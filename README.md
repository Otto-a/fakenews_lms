# Fake News Literacy System

A web-based educational platform designed to empower digital consumers with the critical thinking skills needed to identify, verify and understand the impact of fake news and misinformation. 

## System Visualizations
![Dashboard Visualization](https://github.com/Otto-a/HealthConnect-Final-Analytics---Decision-Support-Package/blob/main/healthconnect_chart_visualizations.png)


## 🚀 Key Features

* **Progressive Learning Engine:** A sequential curriculum where users must watch lessons and pass a module quiz (with a score of at least 60%) to unlock the next level.
* **Practical Lab Evaluations:** Hands-on exercises where users analyze mock articles and identify credibility problems using a red-flag checklist.
* **Course Certification:** The system automatically generates a unique digital certificate once a student successfully passes all modules.
* **Admin Analytics Dashboard:** A real-time data visualization panel (powered by Chart.js) that tracks system enrollments, module completion rates, and individual student progress.
* **Secure Authentication:** Built-in Django security for user registration, password hashing, and session management.

## 🛠️ Technology Stack

* **Back-End:** Python 3, Django Framework
* **Database:** MySQL
* **Front-End:** HTML5, CSS3, JavaScript
* **Data Visualization:** Chart.js
